## Session 2: Ground Items, Persistence, Equipment Fix

### What Happened

**Ground items (drop, render, pick up):**
- Items dropped from inventory now appear on the ground as sprites (MOB/EOB protocol)
- Ground objects render in the object layer between fringe tiles and characters, matching VB6 RenderScreen
- Press G to pick up items at your feet (VB6: GET command)
- One item per tile, "No room on ground" if occupied
- Ground items sent to players on map entry and zone transitions
- Left-click inspection shows "You see a [item name]" for ground objects
- Kyle verified: dropped bread from one character, picked up as another

**Ground item persistence (write-through):**
- Studied VB6 SaveWorld: manual-only button on admin panel, dumps all 211 maps (~38MB binary)
- Our approach: write-through JSON per map (`grounditems/map-NNN.json`), sparse format
- Every drop/pickup immediately persists. Server restart preserves items.
- File deleted when map has no items (no empty files accumulating)

**Equipment anim fix:**
- Equipped weapons/shields disappeared on map transition — all MakeChar broadcasts used hardcoded weaponAnim=2 (invisible)
- Added GetEquipAnims helper that resolves actual equipped item anims from character inventory
- Fixed in PlacePlayerInWorld (login), WarpPlayer (zone transition), and all player MakeChar broadcasts
