### Decisions Made
- **Tech stack**: ASP.NET Core + SignalR + Blazor WASM + Canvas JS interop
- **Project structure**: EraOnline.sln with Shared, Server, Client.Web, Client.CLI projects
- **Map editor**: mode of Client.Web, not a separate app
- **Rendering**: original assets at original resolution, Canvas replicating the Grh system
- **Deployment**: single Azure App Service instance, Server hosts Client.Web
- **Persistence**: TBD, likely CosmosDB (SQLite has issues on App Service's network-mounted storage)
- **Project management**: CLAUDE.md + ARCHITECTURE.md + PROGRESS.md + ORIGINAL_REFERENCE.md + daily logs + journal
