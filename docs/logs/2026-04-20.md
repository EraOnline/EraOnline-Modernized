### Animal Taming Design

Reviewed VB6 implementation:
- `TameAnimal` (GameLogic.bas:5592) — two-pass flow: first call sets `whatjob=14` and sends `DOS` progress bar; second call (after client `XBX` completes the bar) actually applies the tame.
- `DiscardAnimal` (5845), `Transfer` (5817) — simple state flips.
- Inline in TCP.bas: `/STOP`, `/FOLLOW`, `/NAME <name>` — movement pattern switch + rename.
- `NPCAI` case 6 (TamedFollow) — 21×21 scan for owner tile, move one step toward them.
- Data: NPC2.dat has 16 tameable creatures (`SkillNeeded` 5 for giant snake → 99 for dragon/demon). All present in our `npcs.json`.

Kyle chose session-scoped persistence (matching VB6, where NPCs reset on server restart and any player state about owned pets was runtime-only). Commented-out `/ATTACK` and `/SETTLE` in the original left as TODOs in our code — pet combat is part of Era Online's vision, to be added post-port.

### Implementation

**State additions:**
- `NpcState`: `Tamed`, `OwnerCharIndex`, `Attackable` (runtime flag, init from template).
- `PlayerState`: `OwnedNpcIndex`, `PendingTameNpcIndex` (stashed during progress bar).

**Attack validation refactor:** Two call sites (direct melee attack in `Attack`, destruction-spell cast in `CastSpellAtNpc`) now read `npc.Attackable` instead of `template.Attackable`. Direct melee attacks on tamed NPCs get a specific "{name} is tamed and cannot be attacked" message.

**Slash commands** in `HandleSlashCommand`: `/TAME`, `/DISCARD`, `/TRANSFER`, `/STOP`, `/FOLLOW`, `/NAME`. `/TAME` validates (alive, target, tameable, skill, not-already-owned, no-current-pet), then sets `Working=true, WhatJob=14, PendingTameNpcIndex=target.NpcIndex` and sends `CraftStart`. `CompleteCraft` case 14 branches early to `FinishTame` which re-validates all invariants (the 4-second progress window is long enough for state to change), then applies ownership: `Tamed=true`, `OwnerCharIndex=player.CharIndex`, `Movement=TamedFollow`, `Hostile=false`, `Attackable=false`. Plays the NPC's sound, rolls 1/25 on Animal Taming skill, grants +30 EXP.

**Disconnect cleanup:** `OnDisconnectedAsync` calls `ReleasePet` (shared with `/DISCARD`) which restores `Movement=RandomWalk`, `Attackable`/`Hostile` from template, clears Owner/Tamed.

**AI:** `FollowOwner` fills the previously-stubbed `case (int)NpcMovement.TamedFollow` in `TickNpcAI`. Resolves the owner via `GetPlayerByCharIndex`; if offline or on another map, pet idles. Otherwise computes direction via `WorldState.FindDirection` and moves one step per tick.

**Rename broadcast:** `/NAME` sends `ChangeChar` with the new Name across the map; client's existing `onChangeChar` handler rebuilds the character entry, updating the label.
