### Progress Change
- Before: 180/1713 ported (10%), 7 functions tracked, 98 skipped
- After: 236/1713 ported (13%), 63 functions tracked, 5 partial, 10 sections, 103 skipped

### Design Decisions
- `csharpLocation` renamed to `target` so vb6-ast can track ports to any language (JS, TS, etc.)
- Sections are user-defined labels (not VB6 language constructs) allowing sub-function granularity
- Constants get group-level target refs (e.g., "Shared/Constants/Direction.cs") not per-constant refs
- Status report is rendered by Claude from vb6-ast stats output, not a standalone script
- Annotation updates should be included in the same commit as the implementation they track
