## Session 1: NPC AI, Combat, Death, Resurrection — Phase 4 Core

### Context

Started by reading the entire project history in chronological order: Wayback Machine captures of eraonline.net (1999-2004), original VB6 source code, all documentation, screenshots, work logs, journal entries, and the full git history of 51 commits. Running in 1M token context window, so held all of it at once.

### What Happened

**Live NPC Instances (Steps 1-2):**
- Added `NpcState` class to WorldState: position, HP, AI flags, combat stats, loot data — full runtime state paralleling VB6's `NPCList()`
- `SpawnAllNpcs()` iterates all 211 maps at startup, instantiates 2,754 live NPCs from map spawn data
- Each NPC gets a real charIndex allocated from the same counter as players
- Separate NPC tile occupancy dict (`_npcOccupancy`) — `IsTileBlocked` now checks NPC occupancy too
- GameHub sends live NPC positions (not static spawns) on map entry and zone transitions
- `FindNpcAt` queries live NPC tile occupancy for left-click targeting
- NPCs that have wandered from their spawn point show up where they actually are

**NPC AI Movement (Step 3):**
- GameLoopService now drives NPC AI every tick with faithful VB6 probability throttling:
  - Hostile NPCs: 1/4 chance per tick (`RandomNumber(1,4) == 2`)
  - Random walk (type 2): 1/4 chance per tick (`RandomNumber(1,4) == 1`)
  - Standing NPCs (type 1): never
  - All other chase types (3-8): every tick
  - NPCs only tick on maps with players present
- All 8 movement patterns ported: stand, random walk (with VB6's 4/7 valid direction quirk), hostile chase 10-tile, guard patrol, beggar follow, tamed follow, short-range hostile 3-tile, chaotic guard patrol
- `FindDirection` ported exactly including VB6's diagonal bias (NE→NORTH, NW→WEST, SW→WEST, SE→SOUTH)
- `CheckIfAttack` level-gating: NPC won't chase if player level > NPC level + 4 (unless player attacked first)
- Adjacent attack detection: hostile NPCs, normal guards, chaotic guards check 4 adjacent tiles for valid targets before moving

**Bug: SignalR Group Name Mismatch:**
- NPC movements weren't reaching clients — NPCs moved server-side (blocked player movement) but didn't animate on screen
- Root cause: GameLoopService used `"map-{id}"` while GameHub uses `"map:{id}"` — dash vs colon
- One-character fix. Classic.

**NPC AI Speed Tuning:**
- Initial implementation was too fast — NPCs were moving at theoretical 50ms rate
- Kyle pointed out original hardware (Pentium III 700MHz, interpreted VB6, single-threaded) would have had much slower effective tick rate
- Added `NpcAiTickDivisor` constant — AI runs every Nth game tick instead of every tick
- Tuned from 8 (400ms) to 6 (300ms) based on Kyle's gut check against original feel

**Combat — Player Attacks NPC (Steps 4-5):**
- CTRL toggles battle mode with battle music (Mus5), zone music restores on exit
- ALT sends Attack to server — server-authoritative 4000ms cooldown (replacing VB6's client-side timer)
- `UserAttackNpc`: swordmanship hit chance (<=30: 1/3, <=50: 1/2, >50: always), damage = random(MinHIT,MaxHIT) - DEF/2 min 1
- Backstab on first strike: Skill22-based chance for flat 8 bonus damage
- Skill improvement: 1/40 chance each for tactics, swordmanship, parrying per swing
- Attacked NPCs become hostile and switch to chase mode
- Attacking guards triggers criminal status
- Non-attackable NPCs: "A mysterious force prevents you from attacking..."

**NPC Death & Respawn:**
- Corpse object (DeathObj) placed at death position
- Loot roll: 1/LootChance, up to 4 inventory items in adjacent legal tiles
- EXP + gold rewards, reputation changes (guard kill vs monster kill)
- NPC respawns at random legal position on same map
- Slain announcement broadcast to area

**Combat — NPC Attacks Player (Step 6):**
- Adjacent attack stubs now call actual `NpcAttackUser` damage function
- Tactics dodge chance, CanAttack gate (4000ms), gender-specific hurt sounds
- Guard type validation (type 1 = criminals only, type 2 = humans/wood elves/criminals)

**Player Death & Ghost (Step 7):**
- Ghost state (body=16, head=5), Death signal to client
- Restore HP/STA/MAN to max, clear food/drink/criminal status
- Lose EXP/6 (level > 3), gold/5 (level > 5, gold > 299)
- Drop random unequipped item from slots 0-4
- Exit battle mode, restore zone music
- Client status bar: "Find a Priest of Life and type /RESSURECT"

**Resurrection (Step 8):**
- `/RESSURECT` and `/RESURRECT` commands (both spellings, matching VB6)
- Must be dead, must have targeted a Priest of Life (npcType 61) or Healer (npcType 5) within 2 tiles
- Restores original body/head appearance from PlayerState.OriginalHead/OriginalBody
- Chorus sound, broadcasts restored appearance to map

**Turn in Place:**
- Shift+Right/Left = rotate heading clockwise/counter-clockwise without moving
- Faithful port of VB6's `">"` and `"<"` protocol messages (heading ± 1, wrapping)
- Essential for combat: face your opponent without stepping off your tile

**Level-Up System:**
- `CheckUserLevel` called on every kill: if EXP >= ELU, level up
- +5 training points, +1 MaxHP, +2 MaxSTA, +15 MaxMAN, +1 MinHIT/MaxHIT
- ELU scaling by level bracket (2.0x at low levels down to 1.4x at 30+)
- Spell effect sound + voiceover on level up

**Annotation Catch-Up:**
- 21 functions and 13 HandleData sections annotated across 8 data files
- Functions: 77 → 98 ported, Sections: 25 → 38, Overall: 250 → 271 (15%)
- Discovered vb6-ast ANTLR parser stops at ~line 3198 of GameLogic.bas — 5 implemented functions (FindDirection, BackstabNPC, OpenBattlemode, EndBattlemode, NpcRessurect) not in inventory

### Verified by Kyle
- NPC movement: snakes and spiders moving on paths, guards patrolling
- NPC speed: tuned from 8 to 6 tick divisor based on Kyle's feel comparison with original
- Combat: attacked snake, saw hit/miss messages, sword sounds, killed it, got gold + reputation
- Death: killed by a bat, became ghost, saw death messages and item loss
- Resurrection: found Priest of Life on Map 79, targeted and /RESSURECT'd successfully
- Turn in place: Shift+arrows working for facing changes
- Battle music: Mus5 plays on CTRL, zone music restores on exit

### Design Decisions
- NPC AI tick divisor (6) simulates original hardware processing overhead — the VB6 50ms timer was aspirational on a Pentium III
- Server-authoritative attack cooldown (4000ms) replaces VB6's client-side Attack timer — browser F12 can't be used to speed-hack
- NPC charIndex values are positive (allocated from same counter as players) instead of the previous negative hack — renderer handles them identically
- SignalR group names must match exactly between GameHub and GameLoopService — both use `"map:{id}"`

**Phase 5 — All Items Implemented:**

*1. NPC Trading (/TRADE):*

- Client: training overlay with skill names, current values, + buttons

*3. NPC Healing (/HEAL):*
- VB6: NpcHeal (npcType 5), charge = level * 10 gold (cap 200)

*4. Banking (/DEPOSIT, /WITHDRAW, /BALANCE):*
- VB6: BankDeposit/BankWithdraw/BankBalance (npcType 48)
- Simplified from VB6's separate forms to inline commands with amount argument
- Added validation that VB6 was missing (sufficient gold/bank gold checks)

*5. Class Restrictions & Changes:*
- ClassForbid: items have an array of class names that can't use them. Added check to UseItem before the type switch
- Level/HP check: items with Level > 0 require MaxHP >= Level to equip
- CheckClass: called on all skill changes (training, combat, merchant, crafting). Finds highest skill and updates class via SkillToClass mapping

*6. Crafting (3 pipelines):*
- Woodworking: saw + 2 logs → 4 planks; carpentry drawing + planks → item
- Tailoring: sewing kit + 2 cloth → 4 folded cloth; tailor drawing + folded cloth → clothing
- Blacksmithing: hammer + 2 ore → 4 steel; blacksmithing drawing + steel → weapon
- Two-step flow matching VB6: use drawing (sets recipe in Throw state), then use materials (starts craft)
- Server-authoritative progress: duration = (100 - skill) * 50ms, minimum 2s. Client shows animated blue progress bar. Server validates minimum timing on CompleteCraft
- Skill improvement: 1/15 on material processing, 1/4 on item creation. 3 EXP per craft
- Added crafting state to PlayerState (Working, WhatJob, CraftMakeItem, etc.)

*7. Campfire Healing:*
- Use log (OBJTYPE_LOG=20) → SetCamp craft (surviving skill, job 13) → campfire (obj 155) on ground
- DoTileEvents checks adjacent tiles for campfire, sends CampfireNearby to client
- Client starts 10s interval calling CampHeal. Clears on movement, re-enables if still adjacent
- CampHeal: restores HP by maxHP/5, STA by maxSTA/5
